# SupplySentry Portfolio Release v1.0.0

This release packages SupplySentry as a reproducible, bilingual Agent-engineering portfolio project rather than a slide-only demo.

## What is included

- Evidence-driven procurement flow from free-form supplier reply through structured proposal, deterministic validation, human approval, controlled action, durable projection, SLA, risk, notification, and audit.
- English and Simplified Chinese Console and repository documentation.
- An isolated eight-service Docker Compose demo with five synthetic purchase orders and eight scenarios.
- A real short-delivery approval path backed by a persisted confirmation document and line-level quantity evidence.
- Fail-closed public-demo boundaries: fixed tenant, no production mounts or credentials, disabled uploads/configuration/webhooks, generation guards, rate limits, hourly resets, and `simulated_demo` receipts with `externalDelivery=false`.
- A deterministic 240-case supplier-reply evaluation with a committed dataset and reproducible runner.
- Editable Draw.io architecture source, checked-in SVG, 18-second GIF, poster, and a 61-second 1080p walkthrough video attached to this release.

## Evidence and limits

- Deterministic evaluation: 240/240 completed; dataset SHA-256 `4452a076d5d0ea7d0de01fee9ea77007976db0d038b718bda2378c455399b331`.
- Walkthrough SHA-256: `34a88cface93ac82a958271de625acec35014eb7ff2015accbdcf88df3f138d6`.
- All visible data is synthetic. Production connectors are intentionally absent from the demo.
- External delivery is simulated; the video does not claim that email, WeChat, WhatsApp, Hermes, or ERP actions reached a real third party.
- DeepSeek evaluation is not published because a complete 240-call provider run has not been accepted.
- No internet-hosted demo URL is advertised in this release; use the one-command local Docker demo.

## Run locally

```bash
git clone https://github.com/het2333/supply-sentry.git
cd supply-sentry
./scripts/demo/demo.sh up --build
```

Open `http://127.0.0.1:3002` and select **Enter public demo**.
